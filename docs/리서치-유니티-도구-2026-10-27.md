## B. 플레이 테스트 자동화 (computer-use 클릭 대체)

### 현황
computer-use로 에디터 Game 뷰를 직접 클릭. 실측 한계: mouse_move 선행 필요, IMGUI 버튼은 앱 비활성 시 합성 클릭 무시, 좌표 프레임 세션마다 어긋남.

### 조사 결과
1. **InputTestFixture (Unity 공식, 이미 보유)** — [Input System 패키지의 공식 테스트 픽스처](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.20/manual/Testing.html). 플랫폼 백엔드·실제 하드웨어 없이 코드로 입력을 완전히 구동(가상 디바이스 `InputSystem.AddDevice` + 이벤트 주입), 테스트마다 입력 시스템 격리·복원. 이 프로젝트는 `com.unity.inputsystem 1.19.0` + `com.unity.test-framework 1.6.0` + New Input System 사용 중이라 **추가 설치 없이 PlayMode 테스트에서 바로 사용 가능**. mcp-unity의 기존 `run_tests`(PlayMode 지원)로 Claude가 실행·결과 수집까지 가능.
   - 제약: "테스트 코드로 작성된 시나리오"의 반복 검증용. 에디터에서 사람처럼 즉흥 플레이하는 용도가 아님. 또 픽스처 활성 중엔 실제 하드웨어 입력이 차단됨(테스트 격리 설계).
2. **Unity 공식 CLI** — [Unity Learn 튜토리얼](https://learn.unity.com/tutorial/introduction-to-unity-cli) 기준 Pipeline 패키지가 Editor 서버(**Play 모드 제어, 상태 조회, 리컴파일, run_tests, screenshot**)와 Runtime 서버를 호스팅. `unity command editor_play`, `unity command run_tests`, `unity command screenshot` 확인. **입력 주입 커맨드는 확인 안 됨(미확인)**.
3. **Playcaller** ([takashicompany/playcaller](https://github.com/takashicompany/playcaller)) — "Unity판 Playwright MCP" 지향: tap/multi-tap/drag/flick/key 입력 시뮬레이션 + 스크린샷(HDR용 픽셀 읽기 포함) + Play 모드 제어 + Game 뷰 리사이즈. 기능 구성은 요구와 정확히 일치하나 **4★·릴리스 0건으로 성숙도 매우 낮음**. 입력 주입 방식(가상 디바이스 여부)·New Input System 지원 여부 README에서 미확인. 작자 스스로 "빠른 액션 게임엔 부적합" 명시.
4. **IvanMurzak "AI InputSystem" 확장** — 존재만 확인, 기능 상세 미확인.
5. 상용: GameDriver(Input System 1.3+ 대상 입력 시뮬레이션) — 유료, 범위 밖 참고만.

### 권고: **부분 대체 (2트랙)**
- **반복 검증 트랙**: InputTestFixture 기반 PlayMode 테스트를 핵심 조작(던지기→받기, 꺾기 게이지)에 대해 작성하고 mcp-unity `run_tests`로 구동 — 좌표 어긋남·합성 클릭 문제가 원천적으로 없는 결정적(deterministic) 경로. 근거: 전부 이미 설치된 공식 패키지 조합.
- **탐색 플레이 트랙**: computer-use **유지**. 사람 같은 즉흥 플레이를 대체할 성숙한 도구가 아직 없음(Playcaller는 방향은 맞으나 4★). A/C의 스크린샷 경로가 생기면 "보는 눈"은 그쪽으로 이관.

### 전환 비용: **중간**
- PlayMode 테스트 어셈블리(Tests/PlayMode) 신설 + 핵심 조작 1~2개 테스트 작성이 초기 비용. 단 HandController 등 입력 소비 코드가 InputAction 바인딩이면 InputTestFixture와 바로 맞물림.
- 이 변경 자체는 "새 테스트 인프라" = **CAOF Standard~Critical 트랙**으로 별도 계획 필요.
