## 1. 컨셉

전통 공기놀이를 2.5D로 재현한 캐주얼 게임.
**"열받지만 또 하게 되는"** 중독성이 목표.

**핵심 재미 3축**
- **긴장감** — 돌이 떠 있는 동안에만 주울 수 있다
- **좌절 → 재도전** — 실패하면 1단부터. 그래서 "한 판만 더"
- **성취감** — 5단 꺾기 클리어, 그리고 한 생을 끝까지 살아내기

**한 줄 정의:** 공기놀이 한 판이 인생 한 구간이고, 실패하면 처음부터 다시 산다.

## 2. 공간 구조 ★ v17 신규 — 모든 설계의 기반

**판정 공간과 표현 공간을 분리한다.**

| | 정의 | 용도 |
|---|---|---|
| **Board Space** | **완전한 직사각형** (가로로 넓게, 약 16:9) + **높이 `h`** | **모든 게임 로직** |
| **Screen Space** | Board Space를 **사다리꼴로 투영** + `h`만큼 위로 | **렌더링 전용** |

```
[Board Space] 논리 — 직사각형              [Screen Space] 표현 — 사다리꼴
  ┌──────────────────┐                          ╱────────────╲
  │                  │        ──투영──▶        ╱              ╲
  │   균일한 좌표     │                       ╱                ╲
  └──────────────────┘                      ╱──────────────────╲
```

**불변 규칙 — 변환은 양 끝에서 한 번씩만**
```
마우스 입력 ──역변환──▶ [ 로직 전부 Board Space ] ──정변환──▶ 렌더
```

**보드는 배경에서 분리된 별도 오브젝트다.**
배경 이미지는 **분위기 전용**이며 플레이면이 아니다.
보드는 코드가 그리는 **"바닥에 깔린 돗자리"** 로, 배경이 무엇이든(테이블·마우스패드·병상) 그 위에 놓인다.
→ 배경을 갈아도 판정이 흔들리지 않는다. (v11·v12·v14·v16 버그의 근본 차단)
→ ⚠️ 배경에 이미 책상이 그려진 스테이지에서 "이중 책상"이 되지 않도록, 보드는 **깔개**로 디자인한다.

### 이 구조가 없애는 것
- **`SkyFloorY` 소멸** — "이 높이 위는 하늘이라 판정 면제"라는 예외가 사라진다.
  던진 돌은 `h > 0`이라 판정 대상이 아니고, **`h = 0`이 되는 순간에만** 사각형 안/밖을 본다.
- **판정 폴리곤이 하나** — "어느 함수를 쓸까"라는 질문이 소멸.
- **손 이동이 균일** — 사다리꼴 때문에 뒤쪽에서 훅 지나가던 문제 해소.
  화면에선 뒤쪽일수록 느리게 보여 원근감이 오히려 맞아진다.

## 4. 조작 (실제 동작 기준 — v2 문서에서 3건 정정)

| 행동 | 조작 |
|---|---|
| 뿌리기 | **꾹 누르기 → 게이지 왕복 → 놓는 순간의 높이**로 세기 결정 |
| 던질 돌 고르기 | **꾹 누른 채** 커서 이동 → 손 범위에 든 돌 1개 자동 줍기 → 떼면 던지기로 |
| 던지기 | 클릭/탭 → 돌이 하늘로 |
| 바닥 돌 줍기 | **꾹 누른 채** 커서 이동 → 범위에 든 돌 자동 줍기 |
| 받기 | 손이 하늘 영역으로 이동 → **커서 이동**으로 위치 맞춰 받기 |

**⚠️ v2 문서 정정 3건 (모두 실제가 정답)**
| 항목 | v2 문서 (폐기) | v11 확정 |
|---|---|---|
| 받기 | 탭 + 좌우 드래그 | **커서 이동** |
| 줍기 | 클릭 없이 자동 | **꾹 누르고 있어야 줍힘** |
| 줍기 판정 | 돌 면적 100% 포함 | **돌 중심점이 손 범위 안** |

> 줍기가 "클릭 없는 자동"이면, 초과 줍기 즉사(§6)와 겹쳐 **보드 위로 커서를 지나가는 것만으로 죽는다.**
> 꾹 누르기가 그 완충장치다.

### 손 커서
- 손 = 커서. 버튼 호버 시 손 모양이 바뀜(버튼별 지정)
- **속도 상한 유지** — 손은 무게가 있는 물체. 8단 노화손 기믹의 전제
- 5단 받기 진입 시 손 확대 (판정 반경 동반 확대)
- 손바닥 = 안전 / 손가락 = 튕김. 각도·거리에 따른 물리 반응

## 5. 게임 규칙 — 1 루프 = 1 스테이지

- 공깃돌 **5개**로 시작
- **1~4단**: 매 단 시작마다 뿌리기를 다시 함
- **5단**: 뿌리기 없음 (손에 5개 쥔 상태로 시작)
- **어느 단에서 실패하든 1단부터 리셋**

### 1~4단 흐름
```
[뿌리기] 게이지로 세기 조절 → 돌 5개 보드에 퍼짐
   ↓
[던질 돌 고르기] 꾹 누른 채 커서 이동 → 1개 자동 줍기 → 떼기
   ↓
[던지기] 클릭 → 돌이 하늘로 (h 상승)
   ↓
[줍기] 꾹 누른 채 커서 이동 → 목표 개수만큼
       부족 → 계속 줍기 / 초과 → 즉시 실패 / 딱 맞음 → 받기로
   ↓
[받기] 손이 하늘로 → 커서 이동으로 떨어지는 돌 받기
   ↓
 바닥에 돌 남음 → 다시 던지기 / 전부 제거 → 다음 단
```

### 단별 목표
| 단 | 줍기 목표 | 반복 | 실패 |
|---|---|---|---|
| 1단 | 1개씩 | 4회 | 2개 이상 |
| 2단 | 2개씩 | 2회 | 3개 이상 |
| 3단 | 3개+1개 (또는 1+3) | 2회 | 2개 또는 4개 |
| 4단 | 4개 한번에 | 1회 | 3개 이하 |

### 5단 — 꺾기
> 규칙은 유지하되, **코드에서 "5단 전용 분기"는 두지 않는다.** 일반 기믹 구조로 표현한다.

```
[1차 던지기] 클릭 → 손의 돌 5개가 하늘로 (퍼짐 랜덤)
   ↓ [손등 받기] 5개 모두 — 하나라도 놓치면 실패
[2차 던지기] 손등 자세로 쳐올림
   ↓ [손바닥 받기] 5개 모두 낚아챔 — 하나라도 놓치면 실패
```

## 6. 실패 조건

| 유형 | 시점 |
|---|---|
| 장외 — 돌이 보드 밖에 **닿음** | 뿌리기 / 안착 |
| 던질 돌 고를 때 2개 이상 잡힘 | 돌 고르기 |
| **초과 줍기 → 즉시 실패** | 줍기 |
| 체공 시간 초과 | 줍기 중 |
| 떨어지는 돌 못 받음 | 받기 |
| 손등/손바닥 받기 실패 | 5단 |

**체공 시간** — 별도 타이머가 아니라 **던진 돌이 떠 있는 시간(`h > 0`) 그 자체**가 제한이다.

**낙 판정 룰**
- 돌이 **보드 표면에 닿는 순간**(`h = 0`)에만 판정한다. 공중 통과 중에는 판정하지 않는다.
- **보이는 보드 = 판정 경계.** 보이는 것과 판정이 어긋나면 안 된다.
- 놓인 돌(`h = 0`)은 보드 밖이면 낙 / 나는 중인 돌(`h > 0`)은 판정 대상 아님.

## 8. 감각 설계 원칙

> ### 규칙은 가혹하게, 정보는 완전하게.
> 즉사 규칙은 그대로 둔다. 대신 **몰라서 죽는 일**이 없게 한다.
> 죽는 건 플레이어의 실수여야지, 정보 부족이어서는 안 된다.

> ### 정보는 오브젝트 자체가 말한다.
> **HUD·주석·하이라이트를 얹지 않는다.**
> 손 판정 범위 → **손 그림**으로 · 받기 안전 영역 → **손 모양**으로 · 산개 범위 → **링**으로.
> 게임이 화면 위 설명이 아니라 **물리적 표현으로 읽히게** 한다.

**적용**
- 줍기 — 잡힐 돌을 하이라이트하지 않는다. **손 범위를 선명하게** 보여줘 스스로 판단하게 한다
- 받기 — 안전 영역을 따로 표시하지 않는다. **손 모양**으로 전달한다
- 뿌리기 — 게이지는 **범위만** 결정하고 그 안은 랜덤. 매판 다른 상황이 나오는 재미를 남긴다
- 실패 — **즉시 재시작.** 실패 연출을 최소화해 짜증이 바로 재도전으로 이어지게 한다

## 10. v1~v10 → v11 관계

v1~v10은 **폐기하지 않고 이력으로 보존**하되, **현재 기획의 근거로 인용하지 않는다.**
이 문서가 유일한 SOT다. 이후 변경은 델타 문서를 새로 만들지 말고 **이 문서를 직접 갱신한다.**
(델타 누적이 "현재 기획을 아무도 한 번에 읽을 수 없는" 상태를 만든 것이 v10까지의 교훈이다.)
