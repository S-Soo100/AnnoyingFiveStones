## 1. 컨셉

전통 공기놀이를 2.5D로 재현한 캐주얼 게임.
**"열받지만 또 하게 되는"** 중독성이 목표.

**핵심 재미 3축**
- **긴장감** — 돌이 떠 있는 동안에만 주울 수 있다
- **좌절 → 재도전** — 실패하면 1단부터. 그래서 "한 판만 더"
- **성취감** — 5단 꺾기 클리어, 그리고 한 생을 끝까지 살아내기

**한 줄 정의:** 공기놀이 한 판이 인생 한 구간이고, 실패하면 처음부터 다시 산다.

## 2. 공간 구조 ★ v17 신규 — 모든 설계의 기반

**판정 공간과 표현 공간을 분리한다.**

| | 정의 | 용도 |
|---|---|---|
| **Board Space** | **완전한 직사각형** (가로로 넓게, 약 16:9) + **높이 `h`** | **모든 게임 로직** |
| **Screen Space** | Board Space를 **사다리꼴로 투영** + `h`만큼 위로 | **렌더링 전용** |

```
[Board Space] 논리 — 직사각형              [Screen Space] 표현 — 사다리꼴
  ┌──────────────────┐                          ╱────────────╲
  │                  │        ──투영──▶        ╱              ╲
  │   균일한 좌표     │                       ╱                ╲
  └──────────────────┘                      ╱──────────────────╲
```

**불변 규칙 — 변환은 양 끝에서 한 번씩만**
```
마우스 입력 ──역변환──▶ [ 로직 전부 Board Space ] ──정변환──▶ 렌더
```

**보드는 배경에서 분리된 별도 오브젝트다.**
배경 이미지는 **분위기 전용**이며 플레이면이 아니다.
보드는 코드가 그리는 **"바닥에 깔린 돗자리"** 로, 배경이 무엇이든(테이블·마우스패드·병상) 그 위에 놓인다.
→ 배경을 갈아도 판정이 흔들리지 않는다. (v11·v12·v14·v16 버그의 근본 차단)
→ ⚠️ 배경에 이미 책상이 그려진 스테이지에서 "이중 책상"이 되지 않도록, 보드는 **깔개**로 디자인한다.

### 이 구조가 없애는 것
- **`SkyFloorY` 소멸** — "이 높이 위는 하늘이라 판정 면제"라는 예외가 사라진다.
  던진 돌은 `h > 0`이라 판정 대상이 아니고, **`h = 0`이 되는 순간에만** 사각형 안/밖을 본다.
- **판정 폴리곤이 하나** — "어느 함수를 쓸까"라는 질문이 소멸.
- **손 이동이 균일** — 사다리꼴 때문에 뒤쪽에서 훅 지나가던 문제 해소.
  화면에선 뒤쪽일수록 느리게 보여 원근감이 오히려 맞아진다.

## 4. 조작 (실제 동작 기준 — v2 문서에서 3건 정정)

| 행동 | 조작 |
|---|---|
| 뿌리기 | **꾹 누르기 → 게이지 왕복 → 놓는 순간의 높이**로 세기 결정 |
| 던질 돌 고르기 | 돌 위에서 **누르는 순간** 손 범위에 든 돌 1개 줍기 → 던지기로 (빈 곳이면 다시 누름) |
| 던지기 | 클릭/탭 → 돌이 하늘로 |
| 바닥 돌 줍기 | 누른 순간부터 **2초 동안** 누른 채 지나간 돌을 쓸어담기 → 2초가 지나면 떼고 다시 누름 (누를 때마다 2초 새로) |
| 받기 | 손이 하늘 영역으로 이동 → **커서 이동**으로 위치 맞춰 받기. 던진 돌은 옆으로 0.6~1.4 흘러 떨어지고 그림자가 따라간다(2026-11-16, 50살 제외) |

**⚠️ v2 문서 정정 3건 (모두 실제가 정답)**
| 항목 | v2 문서 (폐기) | v11 확정 |
|---|---|---|
| 받기 | 탭 + 좌우 드래그 | **커서 이동** |
| 줍기 | 클릭 없이 자동 | **눌러야 줍힘** (2026-11-15부터 바닥 돌은 누른 뒤 2초 쓸어담기, 던질 돌은 누르는 순간 1회) |
| 줍기 판정 | 돌 면적 100% 포함 | **돌 중심점이 손 범위 안** |

> 줍기가 "클릭 없는 자동"이면, 초과 줍기 즉사(§6)와 겹쳐 **보드 위로 커서를 지나가는 것만으로 죽는다.**
> 누르기가 그 완충장치다.
>
> **2026-11-15 "누르는 순간 집기"** — 누른 채 쓸고 지나가도 더는 안 주워진다. 판정은 누르는 그 순간 1번.
> 이전(누른 동안 매 프레임 판정)엔 누른 채 돌 위를 지나가기만 해도 다 주워져 난이도가 무너졌다(플레이 피드백).
> 하늘(받기 영역)에서 누른 채 보드로 끌고 내려와도 안 집힌다. 방해물(30살)은 여전히 **누르고 있는 동안** 닿으면 실패.
> 줍기 횟수가 시간 비용이 되므로 체공을 단별로 늘린다(§6 체공 시간).
>
> **2026-11-15 2차 — 바닥 돌은 "누른 뒤 2초 쓸어담기"** — 누르는 순간 1회만으론 줍기가 너무 빡빡했다(플레이 피드백).
> 누른 순간부터 2초 동안은 누른 채 지나간 돌이 주워지고, 2초가 지나면 누른 채로는 더 안 주워진다 → 떼고 다시 누르면 2초가 새로 시작.
> 던질 돌 고르기는 여전히 누르는 순간 1회(쓸다 2개 걸려 실패하는 사고 방지). 하늘에서 누른 누름은 쓸기 시간이 없다.
> 단별 체공 배율은 유지(사용자 결정). 쓸기 시간은 `HandController.SweepWindow`.
> (2026-11-16 밸런스: 배율 자체는 유지하되 1.05/1.1/1.15로 축소 — §6 체공 시간)

### 손 커서
- 손 = 커서. 버튼 호버 시 손 모양이 바뀜(버튼별 지정)
- **속도 상한 유지** — 손은 무게가 있는 물체. 8단 노화손 기믹의 전제
- 5단 받기 진입 시 손 확대 — **보이는 손 1.3배, 판정 반경 2배** (2026-10-30 기획 피드백 "손이 확 커짐": 보이는 손만 줄이고 난이도는 유지)
- 손바닥 = 안전 / 손가락 = 튕김. 각도·거리에 따른 물리 반응
  - 1~4단: **튕긴 돌은 다시 손바닥에 닿아도 안 잡힌다** → 떨어져 실패 (2026-11-16. 튕기는 순간 손바닥과 겹쳐 즉시 받기 성공이 되던 허점 제거)

## 5. 게임 규칙 — 1 루프 = 1 스테이지

- 공깃돌 **5개**로 시작
- **1~4단**: 매 단 시작마다 뿌리기를 다시 함
- **5단**: 뿌리기 없음 (손에 5개 쥔 상태로 시작)
- **어느 단에서 실패하든 1단부터 리셋**

### 1~4단 흐름
```
[뿌리기] 게이지로 세기 조절 → 돌 5개 보드에 퍼짐
   ↓
[던질 돌 고르기] 돌 위에서 누르기 → 1개 줍기
   ↓
[던지기] 클릭 → 돌이 하늘로 (h 상승)
   ↓
[줍기] 누르고 2초 안에 돌 위로 쓸기(2초 지나면 떼고 다시 누르기) → 목표 개수만큼
       부족 → 계속 줍기 / 초과 → 즉시 실패 / 딱 맞음 → 받기로
   ↓
[받기] 손이 하늘로 → 커서 이동으로 떨어지는 돌 받기
   ↓
 바닥에 돌 남음 → 다시 던지기 / 전부 제거 → 다음 단
```

### 단별 목표
| 단 | 줍기 목표 | 반복 | 실패 |
|---|---|---|---|
| 1단 | 1개씩 | 4회 | 2개 이상 |
| 2단 | 2개씩 | 2회 | 3개 이상 |
| 3단 | 3개+1개 (또는 1+3) | 2회 | 2개 또는 4개 |
| 4단 | 4개 한번에 | 1회 | 3개 이하 |

### 5단 — 꺾기
> 규칙은 유지하되, **코드에서 "5단 전용 분기"는 두지 않는다.** 일반 기믹 구조로 표현한다.

```
[1차 던지기] 클릭 → 손의 돌 5개가 하늘로 (퍼짐 랜덤)
   ↓ [손등 받기] 5개 모두 — 하나라도 놓치면 실패
[2차 던지기] 손등 자세로 쳐올림
   ↓ [손바닥 받기] 5개 모두 낚아챔 — 하나라도 놓치면 실패
```

## 6. 실패 조건

| 유형 | 시점 |
|---|---|
| 장외 — 돌이 보드 밖에 **닿음** | 뿌리기 / 안착 |
| 던질 돌 고를 때 2개 이상 잡힘 | 돌 고르기 |
| **초과 줍기 → 즉시 실패** | 줍기 |
| 체공 시간 초과 | 줍기 중 |
| 떨어지는 돌 못 받음 | 받기 |
| 손등/손바닥 받기 실패 | 5단 |

**체공 시간** — 별도 타이머가 아니라 **던진 돌이 떠 있는 시간(`h > 0`) 그 자체**가 제한이다.
- 기본: 올라가기 **0.85초** + 내려오기 **1.3초** (씬 직렬화값. 2026-11-16 1.0/1.5에서 단축 — "너무 쉽다, 실제 공기보다 쉽다" 피드백)
- **단별 체공 배율:** 1단 1.0× / 2단 **1.05×** / 3단 **1.1×** / 4단 **1.15×** — 올라가기·내려오기 둘 다에 곱한다.
  2026-11-15에 1.15/1.25/1.35로 넣었으나 같은 날 2초 쓸어담기가 돌아와 줍기 완화가 2중으로 걸려 2026-11-16 축소.
  중력(40살)·모노톤(55살) 낙하 시간 위에도 곱해진다. 플레이로 조정
- **낙하 속도 랜덤 (2026-11-16):** 1~4단 내려오기 속도가 던질 때마다 **1.0~1.3배** 사이 균등 랜덤(낙하 시간 ×0.77~1.0). 기믹 낙하(40·55살) 위에도 곱한다.
  속도는 정점부터 눈에 보이므로 "몰라서 죽음"은 아니다(§8). 5단은 대상 아님
- **5단(꺾기)은 위 단축·랜덤과 무관** — 이전 값(올라가기 1.0 / 내려오기 1.5 기준)에 고정
- 1~4단 체공 실측: 1단 1.85~2.15초 / 4단 2.13~2.47초 (이전 2.5초 / 3.38초)
- 중력(40살) 무게별 낙하는 **기본 낙하 시간** × 배율(검정 0.5 / 회색 1.0 / 흰색 1.8). 이전엔 기준을 1.0초로 잘못 박아 회색도 다른 판보다 33% 빨랐다(2026-11-15 수정)

**낙하 지점 흔들림 (2026-11-16)** — 던진 돌은 수직이 아니라 **보드 가로로 0.6~1.4(보드 단위) 흘러** 떨어진다. (처음 0.4~1.2 → 직접 검증에서 절반쯤 가만히 있어도 받혀 같은 날 넓힘) 방향은 좌우 랜덤, 가장자리에 막히면 반대쪽.
- 흐름은 **올라가는 동안에만** 일어나고 정점부터는 수직 낙하 — 그림자가 정점에서 최종 자리에 멈춰 낙하 내내 조준할 수 있고, 손을 어느 높이에 두든 판정 자리가 같다. 깊이(앞뒤)는 변하지 않는다 → 받기 깊이·손 크기는 그대로
- **그림자가 돌을 따라간다** — 조준선은 유지된다(정보는 오브젝트가 말한다, §8). 받기 판정은 떨어질 자리(= 낙하 중 돌·그림자 자리)
- 손바닥 반경 0.8 / 손 반경 1.6이라, 던진 자리에 손을 그대로 두면 0.8 넘게 흐른 판은 손가락(튕김)이 된다 → 따라가야 받는다
- **50살 시야 제한은 제외(수직 낙하)** — 어둠 속이라 옆으로 흐르는 돌이 안 보인다

**돌 모습 (2026-11-19)** — 표현만 바뀌고 판정(보드 단위)은 그대로.
- **놓인 자세가 돌마다 다르다**: 놓일 때마다 방향 무작위 + 살짝 기울기(앞뒤 ±12° / 좌우 ±4°). 이전엔 전부 같은 각도라 다섯 개가 똑같은 원판으로 보였다.
  기울기를 ±25°로 키우면 원통이 세워진 듯 보여 절반으로 정했다(비교 촬영 후 결정)
- **던진 돌은 비스듬한 축으로 굴러 난다** — 화면 축으로만 돌면 늘 같은 면만 보였다
- **앞뒤 크기 차 완화**: 뒤 돌 = 앞의 약 77% (이전 약 56~60%, 보드 사다리꼴 비율 그대로). 돌 그림에만 적용 — 손·줍기 원·받기 판정은 보드 비율 그대로

**낙 판정 룰**
- 돌이 **보드 표면에 닿는 순간**(`h = 0`)에만 판정한다. 공중 통과 중에는 판정하지 않는다.
- **보이는 보드 = 판정 경계.** 보이는 것과 판정이 어긋나면 안 된다.
- 놓인 돌(`h = 0`)은 보드 밖이면 낙 / 나는 중인 돌(`h > 0`)은 판정 대상 아님.

**보드 변 종류와 낙 연출** (2026-10-28 뿌리기 전면개선 M1 — `docs/계획서-뿌리기-전면개선.md`)
- 스테이지마다 네 변을 **Ledge**(너머가 허공) / **Flat**(같은 높이 바닥이 이어짐)으로 정한다. 앞변은 전 스테이지 Ledge.
  - 10·15·50·55살 전 변 Ledge / 20살 좌우 Flat / 25·30·40·45살 뒤·좌우 Flat / 35살 뒤 Flat, 좌우 Ledge.
- **Ledge:** 돌이 가장자리를 넘는 순간 날던 속도 그대로 아래로 떨어진다. 그 너머에는 그림자가 없다.
  앞변은 화면 밖으로, 나머지 변은 판(테이블) 그림 뒤로 사라진다(판 레이어가 없는 35살은 그 순간 숨긴다).
- **Flat:** 그 바닥에 툭 떨어져 튀고 멈춘다. 그림자도 그 바닥에 생긴다. 판정은 그대로 낙.
- **판정선(D9, 의도된 판정 변경):** Ledge 변은 **보이는 가장자리 = 낙 경계**(뿌리기 마진 0).
  Flat 변은 기존 마진 유지(뿌리기 0.2 보드단위 / 플레이 중 유예 밴드 0.8).
  플레이 중에도 Ledge 변은 보이는 가장자리가 낙 경계다(2026-10-28 M2). **Ledge 뒷변은 "하늘 면제"도 없다** —
  뒷변 너머로 밀려난 놓인 돌은 낙(10·15·20·50·55살). Flat 뒷변은 기존대로 면제.
- **플레이 중 낙 (M2):** 판정은 같은 규칙, 연출만 붙는다.
  - 낙이 나면 **규칙만 멈춘다** — 입력·받기 판정·다른 실패를 막는다. 던진 돌은 받기 판정 없이 바닥에 내려앉고,
    도망 공기·방해물은 계속 움직인다.
  - Ledge로 나간 돌은 위와 같이 떨어진다. Flat으로 미끄러져 나간 돌은 그 자리에서 멈춘다.
  - 손가락에 튕겨 바닥으로 떨어지는 돌은 물리 그대로 떨어지되, 보드 아래로 내려가면 그림자가 없다.
  - 받기 실패(돌을 놓침)는 보드 안에 떨어지는 것이라 낙 연출 대상이 아니다 — 현행대로 즉시 실패.
- 낙 연출은 판정이 아니라 표현만 바꾼다 — 배치·간격 밸런스는 그대로다.

## 8. 감각 설계 원칙

> ### 규칙은 가혹하게, 정보는 완전하게.
> 즉사 규칙은 그대로 둔다. 대신 **몰라서 죽는 일**이 없게 한다.
> 죽는 건 플레이어의 실수여야지, 정보 부족이어서는 안 된다.

> ### 정보는 오브젝트 자체가 말한다.
> **HUD·주석·하이라이트를 얹지 않는다.**
> 손 판정 범위 → **손 그림**으로 · 받기 안전 영역 → **손 모양**으로 · 산개 범위 → **링**으로.
> 게임이 화면 위 설명이 아니라 **물리적 표현으로 읽히게** 한다.

**적용**
- 줍기 — 잡힐 돌을 하이라이트하지 않는다. **손 범위를 선명하게** 보여줘 스스로 판단하게 한다
- 받기 — 안전 영역을 따로 표시하지 않는다. **손 모양**으로 전달한다
- 뿌리기 — 게이지는 **범위만** 결정하고 그 안은 랜덤. 매판 다른 상황이 나오는 재미를 남긴다
  - 게이지를 끝까지 채우면 손이 보드 가운데 있어도 앞뒤로 낙이 난다(최대 반경 4.7 > 보드 반깊이 4.5, 2026-10-30 기획 피드백 "낙이 생길 일이 거의 없다")
  - 2026-10-31 "쫄깃하게": 반경을 최소·최대 모두 +50% → **1.65~7.05**(보드 단위). 가운데서도 게이지 절반쯤부터 낙이 나기 시작하고, 손이 가장자리 쪽이면 더 일찍 난다. 최소가 커져 낮은 게이지의 뭉침 위험은 줄었다
- 실패 — **즉시 재시작.** 실패 연출을 최소화해 짜증이 바로 재도전으로 이어지게 한다
  - 예외(2026-10-28): 낙은 떨어지는 모습이 보여야 원인이 읽히므로, 모든 돌의 움직임이 끝난 뒤 **0.3초**에 실패로 넘어간다
    (뿌리기는 놓은 순간부터 최대 1.6초 — 기존 약 1.7초(비행 + 고정 1.0초 대기)보다 짧다.
     플레이 중 낙은 최대 1.1초 — 기존 즉시 실패보다 길어진 유일한 경우)
