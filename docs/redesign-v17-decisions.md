## 결론 (2026-07-31 확정)

**기획은 하나도 안 버린다. 버리는 것은 수치와 구현뿐이다.**

| 층 | 처리 |
|---|---|
| 기획 (L1~L4, 22항목) | **100% 계승** → 통합 기획서 v11이 곧 재설계 명세 |
| 구조 (코드) | **백지** — 신 객체 해체, 전역 가변 상태 제거, 의도 기반 API |
| 수치 (L5) | **백지** — 전면 재튜닝 |

### 이 결론의 중요한 함의
1. **재설계의 목표가 명확해졌다** — "무엇을 만들 것인가"는 이미 다 정해져 있다. 새로 발명할 기획이 없다.
2. **밸런싱이 작업의 절반이 된다** — 수치를 백지에서 다시 잡는다는 것은 코드 작업이 아니라 **기획+튜닝 작업**이다.
   10 스테이지 × 기믹 × (체공·게이지·산개·판정 범위) 를 새로 잡아야 한다.
3. **플레이 검증의 성격이 바뀐다** — "옛 감각이 유지됐나" 확인이 아니라, **"새 감각을 만드는"** 과정이 된다.
   따라서 플레이테스트는 줄어드는 게 아니라 **재설계 후반부에 집중적으로 필요**하다.
4. **불변식 테스트의 대상이 확정됐다** — 위 22항목이 그대로 불변식 목록이 된다.
   예: 4-3 → "목표 초과 시 실패한다"(수치 무관) / 4-2 → "보이는 보드 밖 = 낙"(좌표 무관)
