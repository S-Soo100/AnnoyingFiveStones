# 유니티용 그래픽·3D 에셋 자체 생성 도구 리서치 (2026-10-27)

> 목적: Claude 워크플로우에서 **그래픽(2D)·3D 에셋을 직접 만들어낼 수 있는 도구** 조사.
> 전제(이 프로젝트/머신 기준): ① 2D 생성은 codex 내장 `image_gen`이 현행 표준(donts/images.md, 사전 승인 룰) ② 구독 내·무료 우선, 모델명 하드코딩 금지 원칙 ③ 머신은 **Mac M5 / 32GB 통합메모리**(CUDA 없음) ④ **Blender 5.2.0 LTS 설치됨** ⑤ 게임이 2.5D라 3D 수요는 돌·소품·타이틀 연출 수준.
> 원칙: 공식 저장소/문서 확인분만 기재, 미확인은 표기.

---

## A. Unity 내장 AI 생성기 (에디터 안에서 생성)

### 조사 결과
- Unity AI(AI Assistant 패키지)의 **Generators**가 에디터 AI 메뉴에서 직접 에셋을 생성: **스프라이트, 텍스처, 머티리얼, 큐브맵, 3D 오브젝트, 터레인 레이어, 사운드 클립, 애니메이션 클립** ([공식 매뉴얼 2.21](https://docs.unity3d.com/Packages/com.unity.ai.assistant@2.21/manual/index.html), [AI 메뉴 문서](https://docs.unity3d.com/6000.2/Documentation/Manual/ai-menu.html)). 애니메이션은 Unity 자체 text-to-animation + Kinetix video-to-animation 모델 병용([Unity 블로그](https://unity.com/blog/unity-ai-ui-generator) 계열 발표).
- 상태: **오픈 베타**(2026-05-04 공개). 베타 중 무료 크레딧 제공, **베타 종료 시 만료 후 유료 전환 예고**. 가격은 [공식 페이지](https://activation.unity3d.com/roadmap/official-pricing) 기준 **월 $10/1,000 크레딧** 구독 또는 Pro 이상 구독 포함(Pro ~300, Enterprise ~400 AI 작업/월), 개인은 14일 무료 체험. 포인트당 단가 확정치는 베타 종료 후 "Preview" 릴리스에서 공개 예정 — **현시점 미확정** ([AI Credits Beta Terms](https://unity.com/legal/unity-ai-credits-terms), 2026-07-28 갱신).
- 설치: `com.unity.ai.assistant` 패키지(Unity 6 이상). 이 프로젝트(6000.3.11f1)는 요건 충족, 현재 미설치.
- 저작권 책임은 사용자에게 있다는 보도 있음([Digital Production](https://digitalproduction.com/2025/08/22/unity-6-2-welcomes-ai-but-pace-caution-user-liability-on-copyright/)) — 약관 직접 확인 필요.

### 권고: **베타 기간 한정 도입 시험**
- 근거: 에디터 안에서 바로 에셋이 생기는 유일한 경로고(임포트 파이프라인 생략), **3D 오브젝트·머티리얼·큐브맵**은 현 체제(codex 2D)에 없는 능력. 베타 무료 크레딧 동안 돌 머티리얼·배경 텍스처로 품질을 가늠해보고, 유료 전환 후 계속 쓸지는 그때 단가 보고 결정.
- 주의: 유료 전환이 예고된 종량제라 "구독 내 무료 우선" 원칙과 장기적으로 충돌 가능. 기본 파이프라인 교체가 아니라 **보조 채널**로.

### 도입 비용: 낮음 (패키지 1개 설치 + Unity 계정 베타 활성화)

## B. Blender 파이프라인 (절차적 3D — 1순위)

### 조사 결과
- **Blender 공식 MCP 서버 존재** — Blender Lab 프로젝트, [공식 페이지](https://www.blender.org/lab/mcp-server/). 자연어→Blender Python API 브리지. **Blender 5.1 이상** 요구 (설치된 5.2.0 LTS 충족). 애드온 v1.0.3 zip + `.mcpb` 번들로 Claude에 연결. ⚠️ 공식 문서가 명시한 보안 경고: **LLM 생성 코드를 가드 없이 실행** — 민감 데이터 없는 환경 권장.
- 커뮤니티 [ahujasid/blender-mcp](https://github.com/ahujasid/blender-mcp) (~28k★ 보도, MIT): 생태계 최대이나 2026년 CVE 4건 보도(경쟁사 블로그 출처라 **요검증**), 공식 애드온과 **포트 9876 충돌** 보고.
- **MCP 없이도 가능**: Blender 헤드리스 실행(`Blender -b -P script.py`)으로 Claude가 bpy 스크립트를 작성→실행→glTF/FBX 출력→`Assets/`로 복사하는 경로는 서버·애드온 설치가 아예 필요 없음. 이번에 검증한 unity CLI `script eval`로 임포트 설정까지 이어짐.

### 권고: **대체(도입) — 3D 소품의 기본 경로로**
- 근거: 이 게임의 3D 수요(공기돌, 타이틀 돌, 소품)는 "텍스트→유기물 3D"가 아니라 **치수가 정확한 절차적 모델링**에 가깝고, 그건 Claude가 bpy 코드로 직접 하는 게 품질·재현성·비용(무료) 모두 우위. 이미 설치된 Blender 5.2 + 기존 Bash 도구만으로 즉시 가동.
- 운용안: 1단계는 **헤드리스 스크립트 방식**(보안 이슈 없음, 세션 로그에 코드가 남아 검수 가능). 대화형으로 씬을 만지는 수요가 생기면 그때 공식 MCP 애드온을 추가(코드 실행 경고 감안, 커뮤니티판 대신 공식판).

### 도입 비용: 매우 낮음 (헤드리스는 0 — 설치 완료 상태 / 공식 MCP는 애드온+번들 설치 30분)

## C. 클라우드 text-to-3D 서비스

### 조사 결과
| 서비스 | MCP | 비용/라이선스 (출처 표기 기준) |
|--------|-----|------------------------------|
| [Meshy](https://github.com/meshy-dev/meshy-mcp-server) | 공식 서버(meshy-dev, 28 tools: text/image-to-3D, 리토폴로지, 리깅, 애니메이션) | **API 키에 Pro 플랜 이상 필요**(README 명시) = 유료. 무료 웹 티어는 CC BY 4.0 + 생성물 공개(2차 보도, 요확인) |
| [Tripo](https://mcp.so/servers/tripo-mcp) (VAST-AI-Research) | 공식 서버 **알파**, 현재 **Blender 연동 전용** | 무료 티어 비상업 보도(요확인), 상업권은 유료 플랜 |
| Rodin (Hyper3D) | 커뮤니티 멀티프로바이더 서버 경유 | 생성 무료·다운로드 유료 보도(요확인) |

### 권고: **보류**
- 근거: 셋 다 실사용은 유료(Meshy MCP는 Pro 플랜 전제)이고, "구독 내 무료 우선 + 유료 API 우회 금지" 원칙과 충돌. 2.5D 게임 특성상 유기물 3D 대량 수요도 없음. 고품질 유기물 모델(예: 캐릭터 손 리모델링)이 **구체적으로 필요해지는 시점에** Meshy 1개월 구독으로 스팟 사용이 합리적.

### 도입 비용: 낮음(npx 1줄) — 단 구독 과금 발생

## D. 로컬 오픈소스 3D 생성 (Apple Silicon)

### 조사 결과
- 공식 지원 없음 — Microsoft TRELLIS.2(4B, MIT 라이선스)와 Tencent Hunyuan3D 2.1 모두 CUDA 전제이고, **Apple Silicon은 커뮤니티 포트만 존재**(2026-04 전후 보도):
  - [TRELLIS-Mac](https://korben.info/en/trellis-mac-microsoft-image-to-3d-apple-silicon.html): PyTorch MPS 포트, **통합메모리 24GB 이상** 권장(이 머신 32GB로 가능권), M4 Pro에서 메시당 ~3.5분 보도. 입력은 **이미지**(텍스트 단독 불가).
  - [hunyuan3d-2.1-mac](https://github.com/VladimirTalyzin/hunyuan3d-2.1-mac): MPS 패치 설치본, M4 Pro 24GB 테스트 보도. ⚠️ **Hunyuan3D 커뮤니티 라이선스가 한국(South Korea)·EU·영국 제외**라는 비교 가이드 보도([Scenario](https://help.scenario.com/en/articles/comparing-generative-3d-models/)) — 사실이면 한국에서 상업 사용 불가. 원문 라이선스 직접 확인 전까지 **사용 금지 권장**.

### 권고: **보류 (관찰)**
- 근거: 커뮤니티 포트 의존 + 이미지 입력 전제 + 메시당 수 분 + 품질이 게임 레디 보장 안 됨. B(Blender 절차적)가 이 게임의 3D 수요를 더 싸고 확실하게 충족. TRELLIS.2가 공식 MPS 지원하면 재평가.

## E. 현행 2D 체제와의 관계
- codex `image_gen`(스프라이트·배경·설정화)은 **유지** — 이번 조사에서 이걸 대체할 이유를 찾지 못함. Unity AI 스프라이트/텍스처 생성기는 베타 무료 동안 **비교 샘플용**으로만.
- 모든 생성 작업은 기존 **사전 승인 룰**(donts/images.md #3) 적용 — 도구가 늘어도 절차는 동일.
